# ai-prompt-helper-ks

Скил (навык) для ИИ-ассистента Kimi. Превращает сырые размытые мысли в чётко структурированные задания для ИИ: контекст, цель, формат результата, ограничения.

## Когда срабатывает

1. Просят составить задание (промпт) для ИИ с нуля.
2. Просят улучшить готовое задание или промпт.
3. Просят проверить задание перед отправкой.
4. Пользователь формулирует задачу размыто, и её нужно структурировать.

## Как работает

1. Определяет режим: составить с нуля, улучшить, проверить или структурировать.
2. Задаёт 2-4 уточняющих вопроса только по критичным пунктам, предлагает варианты ответов.
3. Недостающее некритичное берёт на себя и явно помечает словом «Предположение».
4. Выдаёт готовое задание отдельным блоком, удобным для копирования, под ним список предположений.
5. Если задаче нужны данные из Google-сервисов (Gmail, Drive, Docs, Sheets, Календарь) или результат надо сохранить в них, дополняет задание блоком «Доступ к данным через gws» с командами чтения и записи.

## Структура готового задания

1. Контекст - фон: кто, для чего, в какой ситуации.
2. Цель - что конкретно должно получиться.
3. Формат результата - как выдать: текст, таблица, список; объём, язык.
4. Ограничения - рамки: стиль, сроки, что не трогать.

## Пример

Сырой запрос: «Хочу, чтобы ИИ сделал сайт для бизнеса». Скил задаст 2-4 уточняющих вопроса (какой бизнес, цель сайта, какие страницы нужны), пометит догадки словом «Предположение» и соберёт готовое задание по каркасу выше.

## Установка в Kimi

1. Откройте создание скила командой /skill-creator.
2. Вставьте текст из файла SKILL.md.
3. Сохраните скил и проверьте тестовым размытым запросом.
